# 进步跟踪模板

仅在需要生成、保存或更新学习记录时读取。记录要简洁、可比较，并避免保存不必要的个人敏感信息。

## 学习者画像

```markdown
# IELTS Speaking Profile

- 目标分数：
- 预计考试日期：
- 当前完整估分：
- 评分置信度：
- 当前最大瓶颈：
- 常见话题优势：
- 最近更新：YYYY-MM-DD
```

## 比较规则

只有样本具有可比性时才做趋势判断：尽量使用相同输入方式、相似 Part 覆盖、相近难度和足够回答长度。

用以下标签代替含糊的“进步了”：

- **稳定改善**：至少两个不同问题或两次会话都出现目标行为，且旧问题明显减少。
- **初步改善**：本次出现目标行为，但证据尚少。
- **无明显变化**：可比证据接近。
- **表现波动**：变化可能由话题、紧张、音质或样本长度解释。
- **不可比较**：输入方式或任务差异过大。

量化指标只选择与当前目标有关的 1–3 个，例如：

- Part 2 连续展开时长；
- 每个观点是否包含 reason/example；
- 无功能停顿或重复的频率；
- 目标语法结构的正确使用次数；
- 高频搭配错误是否复现；
- 音频中需要听者额外努力的片段数。

不要把字数、难词数量或连接词数量本身当作能力提升。指标必须与表达质量和官方评分构念相连。
